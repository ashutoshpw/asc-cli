# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use GitHub's
private security advisory reporting for this repository, or contact the
maintainer privately through the address listed in the repository metadata.

Include the affected version or commit, reproduction steps, impact, and any
available mitigation. Do not include App Store Connect private keys, JWTs,
tokens, or other credentials in a report.

## Supported versions

Only the latest `main` commit and the latest published release receive security
fixes. Users should upgrade promptly when a security release is published.
